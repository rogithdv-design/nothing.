# 🐼 Divya's Panda Birthday Wonderland 🎂✨

An interactive, animated cartoon-story birthday website created specially for **Divya**'s birthday on **October 30, 2026**.

Built with **React**, **Vite**, **Tailwind CSS**, **Framer Motion**, and the **Web Audio API**.

---

## 🌟 Key Highlights & Features

- **Cartoon Story Experience**: Designed as a cinematic, interactive animated story rather than a scrolling landing page.
- **Cute Animated Panda Characters**:
  - Original custom vector-rigged SVG pandas.
  - Animated walk cycles, waving arms, jumps, claps, side-to-side grooves, blinking eyes, blushing cheeks, and eating cake.
- **Friendly & Motivational Tone**:
  - Strictly friendly and caring (no romantic wording, no "favorite person").
  - Complete, verbatim college motivation & birthday letter with full readability.
  - One-click **"Save as PDF / Print"** for the letter.
- **Pastel Kawaii Palette**:
  - Pastel Pink: `#FFDDEB`
  - Lavender: `#E9DDFB`
  - Cream: `#FFF9EE`
  - Mint Green: `#C7EAD8`
  - Soft Yellow: `#FFF0B8`
- **Zero-Dependency Audio Synthesizer**:
  - Background music (Kawaii music box melody) synthesized via browser **Web Audio API** (never breaks due to missing mp3 files).
  - Sound effects: spark chimes, blow candles whoosh, cake slice swoosh, panda nibble, cheer fanfares, and gift pop.
  - Mute & BGM toggles (never autoplays without user interaction).
- **Mobile First & Responsive**:
  - Optimized for mobile phones (iOS Safari, Android Chrome) in portrait orientation.
  - Smooth 60fps hardware-accelerated animations, touch-friendly hit targets, and zero horizontal scroll.

## 🎬 The 7 Interactive Scenes

1. **Scene 1 — The Pandas Arrive**  
   Pastel room with garland bunting. Pandas walk in from both sides, wave, jump with balloons, and display speech bubbles ("Hey Divya! 🐼", "It's your special day! 🎉").
2. **Scene 2 — Pandas Bring the Birthday Cake**  
   Pandas push a trolley and deliver a multi-tier birthday cake to the party table. Real interactive "Make a Wish ✨" button blows out candle flames with rising smoke particles and cheer.
3. **Scene 3 — Interactive Cake Cutting**  
   Panda chef approaches with a cake knife and slices the cake. The cake separates into a slice that lands on a dessert plate! Optional "Feed the Panda 🐼" interaction where the panda nibbles the cake with happy hearts and a victory dance.
4. **Scene 4 — Panda Dance Party**  
   Three pandas perform synchronized dances (Jump & Clap, Happy Spins, Side Groove) under a pastel disco ball with balloons and confetti.
5. **Scene 5 — Three Little Birthday Gifts**  
   Interactive gift boxes for *Happiness*, *Confidence*, and *Success (Exams)* with springy pop-up lids and sparkling blessing modals.
6. **Scene 6 — A Special Letter for Divya 💌**  
   Peaceful lavender scene where a panda delivers a wax-sealed envelope. The letter unfolds into a readable card containing the complete, verbatim motivational letter. Includes a sitting panda friend and PDF download/print button.
7. **Scene 7 — Grand Night Finale**  
   Magical starry night sky with moon and fireworks. All pandas return with banners and balloons to wish Divya the happiest year ahead, with a "Replay the Birthday Magic 🎁" button.

## 🚀 Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build
```

---

## 🌐 Deploy to Vercel or Netlify

- **Vercel**: Import the GitHub repository or run `vercel`. The included `vercel.json` automatically configures Vite build output.
- **Netlify**: Connect your repository or drag-and-drop the `dist` folder to Netlify Drop. The included `netlify.toml` handles routing.
